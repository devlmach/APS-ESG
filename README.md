# APS-ESG

Trabalho APS Java LPOO - ESG 

## Introdução

Esse trabalho teve como objetivo a identificação de quanto uma empresa pretende queimar de CO2 anualmente e quanto ela está gastando mensalmente. A partir dessa comparação, sabemos distinguir se ela está ou não batendo suas metas para recuperação do meio ambiente.

## Tecnologias usadas

=== "Java"

    Usamos java para a construção do back-end.

=== "Banco de dados"

    Usamos o PostgreSQL para guardarmos os dados para futuras consultas e armazenamento de dados.

=== "Java Swing e JFreeChart"

    Usamos uma API própria do Java para montagem do front-end além do JFreeChart para criação de interfaces com gráficos.
